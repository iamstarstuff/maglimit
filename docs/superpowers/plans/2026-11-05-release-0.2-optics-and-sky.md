# maglimit 0.2 (optics and sky) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add eyepieces, optics calculations, sky darkness and a sky-aware star limit, exposed through a `maglimit scope` command.

**Architecture:** `Telescope` moves to `telescope.py` and gains an `Eyepiece` type and optics methods. A new `site.py` holds `Site` and the Bortle/SQM/naked-eye maths. A new `cli.py` formats `Telescope.summary()`, which returns plain data. `limiting_mag.py` re-exports `Telescope`, so v0.1 imports keep working.

**Tech Stack:** Python ≥3.10, numpy, astropy units, argparse (no new dependencies), pytest, uv.

**Spec:** `docs/superpowers/specs/2026-10-31-observing-planner-design.md` (§4 CLI, §5.1 inputs, §5.4a point sources, §6 layout, §8 phase 0.2, §9 tests).

## Global Constraints

- Don't break the v0.1 API: `Telescope(aperture, fstop)`, `focal_length()`, `magnification()`, `lim_mag()`, `is_object_observable`, `smallest_scope`, `object_magnitude`, and `import maglimit.limiting_mag`. `test/test_limiting_mag.py` must pass **unchanged**.
- `lim_mag()` stays `2 + 5·log₁₀ D`.
- Units: aperture and eyepieces in mm, angles in degrees, Dawes limit in arcseconds.
- Defaults from spec §5.1: obstruction 0, transmission 0.8, apparent field 52°, eye pupil 7 mm.
- SQM wins if both `bortle` and `sqm` are given.
- No new runtime dependencies. No network access in anything added here.
- Public numeric methods return plain `float` rounded to 2 decimals, like `lim_mag()` and `magnification()`. `focal_length()` keeps returning a `Quantity`.
- Output is plain data first: `Telescope.summary()` returns JSON-serialisable types only (spec goal 7).
- Match existing style: Google-style docstrings, one test docstring per test. `uv run ruff check .` must pass.

## Decisions made in this plan (not in the spec)

- **The sky-aware limit is a new method, `sky_lim_mag()`** (settles the §5.4 naming question). It keeps `lim_mag()` simple and backward compatible.
- **Sky-aware formula.** Spec §5.4a says "following Schaefer (1990)". This plan uses a simplified form of that idea, not his full model, reusing the NELM formula. An eyepiece dims the sky background, so the eye works at a darker effective SQM; the star gains the light the aperture collects. Task 4 has the exact steps. Checked values look realistic (200 mm: 13.77 at low power under SQM 22, 14.55 at a 2 mm exit pupil, 11.21 at low power under SQM 18). It needs comparing with observing reports when the golden cases arrive in 0.3.
- **Bortle → SQM values:** 1: 22.0, 2: 21.9, 3: 21.7, 4: 21.0, 5: 20.0, 6: 19.2, 7: 18.7, 8: 18.2, 9: 17.5.
- **`Site.lat` and `Site.lon` are optional in 0.2**, because `scope` doesn't need a location. `tonight()` will require them in 0.4.
- **The `Observer` class waits** until a release needs it. `eye_pupil` is a keyword argument for now.
- **astroquery stays a required dependency for now.** `import maglimit` takes about 0.8 s, acceptable for a CLI. The §6 optional-extra question moves to 0.3.

## Review Focus

1. Exit pupil larger than the eye's pupil (for example a 40 mm eyepiece on f/5): the eye can't use the extra light, so the limit must go down, not up. Pinned in Task 4.
2. Tiny apertures such as a 5 mm finder, smaller than the eye's pupil: results stay finite and sensible, with no crash. Pinned in Task 4.
3. Typos in values: NaN, infinity, Bortle 10, SQM 200, latitude 95 should give a clear `ValueError`, not silent nonsense. Pinned in Tasks 1 and 3.
4. Malformed CLI input (`--eyepieces 32,,abc`, or `--aperture 0`) should print a one-line error and exit 2, with no traceback. Pinned in Task 5.
5. `maglimit scope` used outdoors with no network, and with no eyepieces or no sky given: it must still print a useful summary. Pinned in Task 5.

  - `dawes_limit() -> float` (arcsec) = 116 ÷ aperture.

- [ ] **Step 2: Run the tests.** Expected: FAIL (`AttributeError`).
- [ ] **Step 3: Implement.** The test values were computed from exactly this:

```python
tau = transmission * (1 - obstruction**2)
xp = eye_pupil if eyepiece is None else exit_pupil_unrounded
d_eff = aperture * min(1, eye_pupil / xp)        # the eye cuts off light beyond its pupil
xp = min(xp, eye_pupil)
sky = site.sqm - 2.5 * log10(tau * (xp / eye_pupil) ** 2)   # dimmed background
limit = naked_eye_limit(sky) + 2.5 * log10(tau * d_eff**2 / eye_pupil**2)
```

Explain the two parts in the docstring and state that this is a simplified model after Schaefer (1990).
